# 超慢跑 Super Slow Jog

Android 超慢跑 App（Kotlin + Jetpack Compose）。

## 功能
- **時間**：10 分鐘為單位（10–180 分鐘）
- **步頻**：150–250 步/分，跑步中也能即時調整
- **開始前 3、2、1 倒數**（語音 + 動畫）
- **跑步動畫**：跟節拍同步的跑者、節拍光環、左右腳指示、進度圓環（每 5 分鐘刻度）
- **每 5 分鐘語音提醒**：已跑 / 剩餘時間 + 跑步小提醒，最後一分鐘提醒
- **男聲 / 女聲**語音，可挑選手機語音引擎內的其他聲音
- **8 種節拍聲**（即時合成）：水滴、木魚、節拍器、木琴、拇指琴、竹筒、頌缽、輕鼓；左右腳可不同音高
- **步數、卡路里**（依體重與步頻的 METs 估算）
- **日 / 月 / 年統計**：長條圖、累計時間、步數、大卡、連續天數
- **直向 / 橫向 / 自動旋轉**：設定裡選，跑步畫面右上角可快速切換；橫放時每個畫面重新排版
- 鎖螢幕也會持續（前景服務），可與音樂同時播放

## 安裝
到 [Releases](../../releases/latest) 下載 `super-slow-jog.apk` 安裝。之後的新版可直接覆蓋，紀錄會保留。

## 建置
推到 `main` 後 GitHub Actions 自動編譯並發布。建置摘要會寫到 `ci-logs` 分支的 `logs/latest.txt`。
