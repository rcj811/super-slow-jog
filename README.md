# 超慢跑 Super Slow Jog

Android 超慢跑 App（Kotlin + Jetpack Compose）。

## 功能
- **時間**：10 分鐘為單位（10–120 分鐘）
- **步頻**：160–220 步/分，每格 5，跑步中也能即時調整
- **開始前 3、2、1 倒數**（語音 + 動畫）
- **原地超慢跑動畫**：角色跟著節拍原地小步跑（鴨子、小狗、小貓、水豚、小男孩、小女孩、兔子、熊貓），也可以用「我的照片」當頭像（拖曳圓圈選位置、兩指縮放，之後可再調整）；畫面上只有角色會動，進度圓環保持靜止（每 5 分鐘刻度）
- **角色體型依身高體重變化**：越高腿越長、體重越重身形越圓潤（可關閉）
- **第一次開啟的設定流程**：身高體重、陪跑角色、運動時間與步頻、每日提醒時間；之後都能在設定修改或重新執行
- **每日運動提醒**：每天固定時間通知，當天已達標就不打擾
- **YouTube 播放**：設定裡加入 YouTube 網址（可一次貼多個、數量不限），跑步時角色區變成 YouTube 播放器，上方顯示剩餘時間；音量可單獨調整、可隨機播放
- **完成時角色歡呼**
- **每 5 分鐘語音提醒**：已跑 / 剩餘時間 + 跑步小提醒，最後一分鐘提醒
- **男聲 / 女聲**語音，可挑選手機語音引擎內的其他聲音
- **16 種節拍聲**（即時合成）：水滴、木魚、節拍器、木琴、拇指琴、竹筒、頌缽、輕鼓、拍手、馬蹄、牛鈴、三角鐵、泡泡、啾啾、彈簧、玻璃彈珠；左右腳可不同音高，音色可由柔和調到尖銳
- **步數、卡路里**（依體重與步頻的 METs 估算）
- **日 / 月 / 年統計**：長條圖、累計時間、步數、大卡、連續天數
- **自訂音量**：節拍（0–150%，超過 100% 柔和加強不破音）與語音分開調，也可直接調手機媒體音量；跑步中點右上角喇叭即可調整
- **直向 / 橫向 / 自動旋轉**：設定裡選，跑步畫面右上角可快速切換；橫放時每個畫面重新排版
- **清除資料**：設定回到初始值、清除跑步紀錄、或全部清除
- 鎖螢幕也會持續（前景服務），可與音樂同時播放

## 安裝
到 [Releases](../../releases/latest) 下載 `super-slow-jog.apk` 安裝。之後的新版可直接覆蓋，紀錄會保留。

## 建置
推到 `main` 後 GitHub Actions 自動編譯並發布。建置摘要會寫到 `ci-logs` 分支的 `logs/latest.txt`。
